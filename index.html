Project settings

The Supabase URL and public key are saved in this browser only. Add the same configuration on each device. Never use a Supabase service-role key in the website.

To share one register across computers and phones, use the same Supabase project and user accounts. Keep database row-level security enabled.

Consent and privacy

Only add members who have agreed to receive WhatsApp messages. Provide a clear way to opt out, do not upload sensitive information, and keep the member list limited to authorized church users.
